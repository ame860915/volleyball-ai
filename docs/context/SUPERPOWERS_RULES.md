# SUPERPOWERS_RULES

> **狀態：Superpowers 外掛未安裝、未驗證。** 以下為手動遵守的工作方式，不代表外掛已啟用。安裝並確認可用後再更新此行。

## 工作方式

1. **先規劃再寫碼**：動手前寫出 Flow 與 Plan（見 `CLAUDE.md` 的 Flow First 7 步）。
2. **拆小任務**：每個任務 1–3 小時內可驗收；超過就再拆。
3. **測試先行**：先寫或列出測試案例，再實作。
4. **證據優先**：宣稱「完成」必須附上實際執行的輸出。
5. **Review**：完成後產出 Review Brief，交由 Codex 獨立檢查。
6. **卡住時**：同一問題嘗試 2 次失敗，就停下來整理現象、假設與已試方法，再決定下一步，不盲目重試。
